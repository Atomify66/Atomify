## Structura proiectului

## Instalare & documentație

Vezi [`v2/DOCUMENTATIE_COMPLETA.md`](./v2/DOCUMENTATIE_COMPLETA.md) pentru:
- Cerințe de sistem și dependențe
- Instrucțiuni complete de instalare
- Arhitectura aplicației
- API routes
- Configurație Nginx, PM2, SSL

## Tech stack

- **Backend:** Node.js, Express, SQLite
- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Generare izomeri:** MAYGEN (Java)
- **Auth:** Sessions + Google OAuth
- **Deploy:** Nginx reverse proxy + PM2 + Let's Encrypt SSL
